# Decision log: written justification for every modelling choice

| ID | Decision | Alternatives considered | Why |
|---|---|---|---|
| D-01 | **36-month loans only** | all terms; 36+60 with term as a feature | The file is a 2018Q4 snapshot. 36m loans are fully matured only if issued by Dec-2015, 60m only by Dec-2013. Mixing terms mixes maturity windows and makes vintage default rates incomparable. |
| D-02 | Target: Charged Off/Default=1, Fully Paid=0; Current/Late/In Grace excluded | treat Late as default; treat Current as good | Final outcome is unknown for in-flight loans; assuming it biases PD (and later vintages disproportionately). Excluded rows are kept in `model_frame` (target NULL) for PSI. "Does not meet the credit policy" statuses are excluded: different underwriting policy. |
| D-03 | Train 2007-14, **clean validation 2015**, 2016 flagged-censored, 2017-18 PSI only | 2015-18 as validation | 2016+ 36m vintages are not fully matured: resolved subset over-represents early defaults, which distorts decile calibration and provisioning. Original window kept as a possible sensitivity run, not the headline. |
| D-04 | NaN kept; own WoE bin; no imputation; winsorise at train 0.5/99.5 pct | median imputation; drop rows | Preserves missingness signal; limits learned on train only. `dti` outside [0,100] and non-positive income treated as invalid. |
| D-05 | Own WoE/IV binner (monotone merge, min bin 5%, +0.5 smoothing); scorecardpy/skorecard only as cross-check | scorecardpy as primary | Version-compatibility risk; owning the code makes it unit-testable and auditable. |
| D-06 | WoE = ln(bad/good) | ln(good/bad) | Positive coefficients expected, making sign checks trivial. IV unaffected. |
| D-07 | Champion excludes LC `int_rate`/`grade`/`sub_grade` | include them | They are LC's own risk output (circular). `with_lc` and `grade_only` rows quantify incremental lift. |
| D-08 | `funded_amnt`, `out_prncp`, `recoveries`, `total_rec_prncp` banned from PD features (code guard + tests); used only for EL proxies | none | Post-origination / outcome-linked: leakage. |
| D-09 | Class weights (balanced), not SMOTE | SMOTE | No synthetic observations; SMOTE tested once and reported as a negative result for calibration/provisioning. |
| D-10 | Recalibrate with Platt on **train OOF** scores | fit on validation; isotonic | Validation fit = leakage; in-sample fit optimistic for GBM; Platt has 2 parameters and is stable. OOF folds are shuffled: acceptable because OOF scores only fit the calibrator and are never used to estimate performance; use a time-ordered split if ever reused for evaluation (D-19). |
| D-11 | Oracle intercept shift shown as **diagnostic only** | use as model | It consumes validation outcomes. |
| D-12 | LightGBM with monotone constraints and strong regularisation | unconstrained GBM, XGBoost | Economic sign constraints; limits regime overfit. Promotion rule: Gini uplift >= 0.02 and no calibration deterioration, stated before results. |
| D-13 | Threshold by EL-vs-approval-rate with an **assumed** appetite | F1/Youden | F1 ignores exposure, LGD and appetite; the appetite is an explicit config input. |
| D-14 | PSI labelled distribution-shift only | use as performance evidence | PSI uses no outcomes. |
| D-15 | LGD/EAD: single exposure-weighted proxy from train defaults | beta regression, segmentation | Scope is PD; proxies are illustrative and labelled as such. |
| D-16 | **Snapshot = 2018-12-31; `fully_matured` = explicit `issue + term <= snapshot`; clean months must also be >=95% resolved** (months failing are demoted to the flagged sample and listed in the memo) | snapshot 2018-12-01; `date_diff('month')` | Review finding. The file runs to end-Dec-2018, so Dec-1 wrongly cuts a month of resolutions and adds non-random residual censoring at the window edge. `date_diff('month')` ignores day-of-month (tested: it calls 2015-12-15 "36 months" against 2018-12-01 although issue+36m is later), so the logic is now explicit date arithmetic, pinned by a test that runs the real SQL. The resolution-share audit is an empirical check on top, because a loan whose 36th payment falls at the snapshot may not yet be recorded as resolved. |
| D-17 | Rare-category pooling label is the reserved sentinel `_POOLED_`; data containing it is rejected | pooling into `"OTHER"` | Review finding. Lending Club `home_ownership` has a real `OTHER` level; pooling under the same label blended a genuine segment with rare-level noise, unrecoverable from the bin table. |
| D-18 | Raw-load row-count floor (`loader.min_raw_rows`), `reports/load_audit.json`, failed builds delete the DB | trust `ignore_errors` | Review finding. `ignore_errors=true` can drop malformed rows (free-text `desc`) silently and non-randomly. The floor and audit make loss visible; they cannot prove it is zero. Set the floor to `null` for slices. |
| D-19 | OOF shuffled-KFold rationale documented in `oof_proba` | TimeSeriesSplit | Review finding; see D-10. TimeSeriesSplit would leave the first fold without OOF scores. |
| D-20 | PSI falls back to value counts when quantile edges collapse (<3 unique edges); NaN is its own category; `emp_length` literal null strings normalised | leave as is | Review findings. Collapsed bins made PSI 0 by construction for skewed discrete features such as `delinq_2yrs`; "nan"/"None" strings were mapped to Unknown only by accident. |
